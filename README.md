# AI vaistų atpažinimas

Edukacinis prototipas, jungiantis 24 klasių HOG + Logistic Regression modelį su vaistų sąveikų paaiškinimo sąsaja.

## Paleidimas
`streamlit run app.py`

## Svarbu
Tai nėra medicininė diagnostikos ar gydymo sistema. Sąveikų duomenys turi būti patikrinti pagal patikimus vaistų informacijos šaltinius prieš naudojant demonstracijoje kaip faktinę klinikinę informaciją.
